# 调度故事板

**LibTV 公开说明**：生成带有运动轨迹等调度草图分镜。输入 10–15 秒的小剧情，整理为 4–6 个中文调度分镜手绘版。

**什么时候用**：开拍前要先说清“人往哪走、镜头怎么动”。适合动作戏、走位、广告运镜。

## 可直接粘贴的模板

```text
Create a director's shot-planning sheet for one continuous [10-15]-second scene,
laid out as [4-6] clearly separated panels in reading order left-to-right, top-to-bottom.

STORY: [one short scene with a clear beginning, action, and reaction]
LOCATION: [place, time of day, weather]
IDENTITY LOCK: [character name, age/build, face, hair, exact outfit] — identical in every panel.
CAMERA PLAN: [wide establishing] → [medium follow] → [close-up] → [reaction/reveal].

Each panel is a clean hand-drawn previs frame on white paper: loose gray pencil line work,
minimal flat gray shading, no rendered lighting.

MOTION ANNOTATION: in every panel draw one thin red camera-path arrow showing the camera
move (push in / pull out / pan left / pan right / orbit / tilt up / tilt down). Draw one
blue arrow for the character's walking path. Arrowheads must be clean and readable.

In the lower margin of each panel, write only the shot code and seconds, in small clean
uppercase sans-serif: [A / 0-2s], [B / 2-5s], etc. No dialogue, no paragraphs, no watermark.

Consistent screen direction, same costume and hair across all panels, no extra characters.
Aspect ratio 16:9.
```

## 填写要点

- `[4-6]` 是 LibTV 公开说明里的范围；格子太少讲不清走位，太多会画糊。
- 红箭头只表示**镜头**，蓝箭头只表示**人物**；两套颜色要在模板里写死。
- 想要纯黑白草图，删掉红蓝箭头描述，改成 `black arrows`。
- 如果用于视频首帧，再跑一次“故事板”或用「电影级光影校正」补光影。
