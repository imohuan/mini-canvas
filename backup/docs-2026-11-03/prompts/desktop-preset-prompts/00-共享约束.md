# 共享约束（所有模板共用）

## 三句话原则

1. **先说结果**：要生成一张什么图，几个格子，横的还是竖的。
2. **再锁不变项**：同一个人、同一件衣服、同一盏光、同一台相机。
3. **最后列禁区**：不要文字、不要水印、不要多余角色、不要改变脸。

## 角色锁定句

在每格重复同一段人物描述，不要写「同一个人」。可复制：

```text
Identity lock: the exact same character in every panel — same face shape, skin tone,
eye color, hairstyle, body proportions, outfit, and accessories. Do not change age,
species, gender presentation, or costume between panels.
```

## 产品锁定句

```text
Product identity lock: preserve the exact silhouette, proportions, material, color values,
label placement, logo, and packaging geometry. Do not redesign, restyle, beautify, or add
alternate branding.
```

## 画风锁定句

```text
One consistent art direction across the entire image: [photorealistic / cel-shaded anime /
painterly concept art / clean line art]. Same line weight, same palette, same rendering
medium in every panel.
```

## 常见失败与修法

| 现象 | 原因 | 改法 |
|---|---|---|
| 九宫格被画成一大幅单图 | 没写格子数量与分隔线 | 第一句写 `3x3 grid, 9 clearly separated panels`，加 `thin white gutters` |
| 每格脸不一样 | 只说「consistent character」 | 每格逐字重复同一段人物描述，并写 `identity lock` |
| 文字乱码 | 模型在格子里硬写中文 | 要求 `no captions, no labels, no text`，文字后期加 |
| 全景接缝明显 | 没有规定投影与宽高比 | 写 `equirectangular projection, 2:1, seamless left-right wrap` |
| 三视图变成三张不同的人 | 没有统一身高线与基线 | 写 `same baseline, identical height, front / side / back` |
| 修图后像换了个人 | 只写「更好看」 | 先写 `preserve identity, pose, framing`，再写只改什么 |

## 尺寸建议

- 故事板 / 九宫格 / 二十五宫格：横版，优先 16:9；25 格可用 1:1 或宽幅长图。
- 三视图 / 设定图：竖版或方形，优先 3:4、4:5、1:1。
- 720 全景：**必须 2:1**（例如 4096×2048）。
- 人像与光影校正：沿用原图比例，不裁掉主体。

## 输出前检查

- [ ] 格子数量写死，且与画面分隔线一致。
- [ ] 人物 / 产品锁定句已逐字重复。
- [ ] 光线有来源、方向、软硬、色温，不只写「电影感」。
- [ ] 禁止项明确：无文字、无水印、无多余肢体、无换装。
- [ ] 宽高比和投影方式写清楚。
