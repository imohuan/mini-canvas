# 画面推演 - 3秒后

**LibTV 公开说明**：基于物理逻辑，生成 3 秒后的动作结果。

**什么时候用**：动作片、体育、舞蹈、产品使用演示，要预测接下来一瞬。

## 可直接粘贴的模板

```text
Starting from the supplied image, generate a single frame showing the same scene exactly
3.0 seconds later. Do not create a comic grid; output one cinematic still.

PRESERVE FROM SOURCE IMAGE: exact character identity, face, hair, body proportions,
wardrobe, props, location, camera position, lens, framing, palette, and lighting direction.
Do not crop the subject, do not change the background layout, do not add new characters.

PHYSICAL CONTINUATION — reason step by step, then render only the final frame:
1. Current velocity and body weight: [direction, speed, support foot, hand position].
2. Gravity, friction, and collisions for the next 3 seconds: [what falls, swings, spills].
3. Resulting pose: [where the body lands, which limb leads, cloth and hair follow-through].
4. Environmental result: [dust, splash, smoke, light flicker, object displacement].

Render the most probable outcome, not an artistic montage. Motion blur only where the
movement is genuinely fast. Same lens and exposure as the source. No text, no watermark.
Photorealistic cinematic still, aspect ratio same as source image.
```

## 填写要点

- “3 秒”是硬条件；模板里保留 `exactly 3.0 seconds`，不要改成模糊的“after a while”。
- 如果原图是静止摆拍，先补一句“the character begins to move at t=0”，否则模型只会换表情。
- 需要多帧时，把这个模板重复 3 次，分别写 1 秒 / 2 秒 / 3 秒。
