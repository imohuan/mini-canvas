# 电影级光影校正

**LibTV 公开说明**：调整画面光影质感；对当前图像做电影机光影矫正；支持文本 / 参考图。

**什么时候用**：构图和人物都对，但光太平、没有层次。

## 可直接粘贴的模板

```text
Relight this image only. Keep the scene, subject, pose, framing, camera position, lens,
perspective, background geometry, colors of objects, and identity completely unchanged.

SCENE LOCK: constant background, fixed scenery, static shot, fixed viewpoint, no camera move.
RELIGHTING ONLY: change light rays and shadows; everything else stays untouched.

TARGET LIGHT: [golden hour / blue hour / soft window light / single hard spotlight /
studio softbox / overcast daylight].
KEY LIGHT: from [camera-left / camera-right / top / behind] at [30-45] degrees,
[warm 3200K / neutral 5500K / cool 6500K], [soft / hard].
FILL: [soft bounce from the opposite side / cool ambient] at [low / medium] intensity.
RIM: [subtle warm rim on hair and shoulders / none].
SHADOW BEHAVIOR: [soft falloff / crisp contact shadows], preserve ground contact.

Cinematic color grade: [teal shadows + warm highlights / neutral cinematic / muted film stock].
Natural skin tones, realistic global illumination, ray-traced shadows, no color spill on skin.
No added objects, no new background, no text, no watermark. Keep original aspect ratio.
```

## 填写要点

- 不写“电影感”，写清光源、方向、软硬、色温；抽象词只会得到通用暖光。
- `SCENE LOCK / RELIGHTING ONLY` 要原样保留，这是防止换背景的关键。
- 需要调色时单独加一句 `apply color grade only after relighting`。
