# 角色三视图

**LibTV 公开说明**：一键生成角色三视图（正面 / 侧面 / 背面），白底，带正面肖像特写。

**什么时候用**：给同一个角色做后续分镜、换装、视频；先锁住长相和比例。

## 可直接粘贴的模板

```text
Character turnaround sheet of [character name], [age band / build / species], wearing
[exact outfit, shoes, accessories]. Four views on ONE clean white canvas, arranged left
to right: front view (facing camera), three-quarter side view (turned 75 degrees right),
side profile (facing right), back view (facing away). Add one small head-and-shoulders
front portrait in the upper-right corner, clearly separated from the body views.

IDENTITY LOCK: identical face, skin tone, eye color, hairstyle, body proportions, height,
outfit, and accessories in every view. Same neutral standing pose, arms relaxed at sides,
feet on one shared baseline. Do not change age, gender presentation, or species.

LAYOUT: thin #CCCCCC horizontal height lines at head, shoulder, waist, knee, and foot level,
spanning the full width. Small color swatches with hex values connected to the outfit by
thin #999999 leader lines. Generous margins, no overlap between views.

Flat even studio lighting, no cast shadows, no gradient background, no props, no extra
characters, no text besides the tiny hex labels, no watermark. [photorealistic /
cel-shaded anime / painterly concept art] rendering, consistent line weight.
Aspect ratio 3:4.
```

## 填写要点

- 三视图不是“三个不同姿势”：姿势、表情、光线必须一致，只有朝向变化。
- 想要游戏建模可用，保留身高线和色卡；只做插画可删掉这两项。
- 如果只要正 / 侧 / 背、不要肖像，删掉 `small head-and-shoulders` 那句。
