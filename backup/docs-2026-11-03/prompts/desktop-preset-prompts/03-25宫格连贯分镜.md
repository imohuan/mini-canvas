# 25宫格连贯分镜

**LibTV 公开说明**：生成连续分镜长图，基于当前图像做 25 宫格剧情推演。

**什么时候用**：一个动作、一段对话或一条产品动线，要拆得很细，方便直接挑镜头或做逐格视频。

## 可直接粘贴的模板

```text
Create one tall storyboard sheet with exactly 25 panels in a 5x5 grid, telling one
continuous [20-25]-second sequence. Read order: left to right, top to bottom.

SOURCE IMAGE: use the supplied reference image as the visual anchor for the character,
wardrobe, location, palette, and lighting. Preserve all of them in every panel.

IDENTITY LOCK: [exact character description]. Same face, hair, body proportions, outfit,
and props in all 25 panels. No age drift, no costume change, no extra characters.
SCENE LOCK: [location with fixed landmarks]; [time of day]; [named light source].

BEAT MAP:
Row 1 (beats 1-5): [setup — character enters / notices / reaches].
Row 2 (beats 6-10): [approach — first obstacle, closer framing].
Row 3 (beats 11-15): [turn — the decisive action, strongest contrast].
Row 4 (beats 16-20): [consequence — reaction, environment changes].
Row 5 (beats 21-25): [resolution — final pose, calm hero frame].

Each panel is a distinct camera setup with a clear change in shot size or angle from its
neighbors. Thin white gutters, uniform panel size, no text, no labels, no numbering,
no watermark. Cinematic [photorealistic / stylized 3D / anime] rendering, consistent grade.
Aspect ratio 3:4 vertical sheet.
```

## 填写要点

- 25 格不是 25 张“差不多的图”：每行要有明显推进，隔格至少换一次景别。
- 长图容易在底部掉细节；把最关键的动作放在第 11–15 格。
- 如果模型把 5×5 画错，第一句改成 `exactly 25 panels arranged in five equal rows of five`。
