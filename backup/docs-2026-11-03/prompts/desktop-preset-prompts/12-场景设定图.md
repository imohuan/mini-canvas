# 场景设定图

**LibTV 公开说明**：场景设定图。用于把一处环境拆成可复用的空间参考。

**什么时候用**：同一地点要出现很多次；先锁建筑、材质、光源和出入口。

## 可直接粘贴的模板

```text
Create a scene design sheet for [location name], a [genre / era] environment.
One organized layout, no characters in any view. Clean neutral presentation board.

SCENE LOCK: [architecture, materials, palette, fixed landmarks, entrances and exits,
weather, time of day]. The same place in every section — do not invent a new layout.

LAYOUT:
- Main image (60%): wide establishing view from [camera height], showing the full space
  and its dominant light source.
- Top strip: four small orthographic views of the same space — front, back, left, right —
  identical proportions and landmarks.
- Lower left: key landmark detail — [door / counter / statue / window] with material close-up.
- Lower middle: lighting variant — [day / dusk / night] with the same architecture and camera.
- Lower right: [4-6] color swatches with hex codes for walls, floor, accent, light.

Consistent perspective and scale across all views. Thin gray divider lines, small clean
labels only, no decorative border, no watermark. Photorealistic architectural previs /
painterly concept art. Aspect ratio 4:5.
```

## 有空镜需求时

把主图改成：`empty scene, no people, only still environment`；并在末尾重复一次。

## 填写要点

- 场景设定图最重要的是**固定地标**：门窗、招牌、柱子、楼梯的位置不能每个视角都变。
- 昼夜变体只改光，不改建筑；把 `same architecture and camera` 留在一句里。
- 没有人物时明确写 `no characters in any view`，否则模型会加路人。
