Agent 工具卡 · 样式候选

同一批工具调用（6 个）在四种方案下的样子。面板宽度、底色、圆角、边框都按真机复刻（400px 宽、#212121 底、28px 圆角），工具是真实数据（exec_command / read_file / canvas_get / resource_list / generation_status / canvas_batch_nodes）。

我的建议：B（紧凑两行） —— 画布卡片压到 2 行以内，需要“看效果”的地方只留一枚 40px 缩略图，列表类（resource_list）不再铺图、只给计数；普通工具（exec_command 这类）维持现在的单行折叠行不动。A 最省空间、C 适合图多的流程、D 是当前线上样式作对照。看中哪套告诉我编号即可。

A · 单行极简

每个工具就一行（26px）：图标 + 名字 + 一句人话。媒体只留 20px 小图，列表只报数字。点行展开详情。
