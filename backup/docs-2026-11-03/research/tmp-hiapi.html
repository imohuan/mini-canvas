一个任务 API，贯通所有生成工作流

提交任务、查询状态、接收回调、取回已存产物，同一套简洁生命周期全部搞定。

  • model

    传入基础模型名，即可用同一接口调用任意模型。

    必填
  • input

    各模型专属参数，按请求逐一校验。

    必填
  • route

    可选线路参数，如 beta、ext；不传或传 default 即默认线路。

    可选
  • storage

    设为 persistent，取回低成本的持久产物链接。

    可选
  • callback

    任务完成即回调通知，免去轮询。

    可选
POST /v1/tasks
curl https://api.hiapi.ai/v1/tasks \
  -H "Authorization: Bearer $HIAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-42-submit" \
  -d '{
    "model": "gpt-image-2.5-flare/text-to-image",
    "route": "default",
    "input": {
      "prompt": "a glass speaker, studio light",
      "aspect_ratio": "1:1",
      "resolution": "1K"
    },
    "storage": "persistent",
    "callback": {
      "url": "https://example.com/cb",
      "when": "final"
    }
  }'
先返回任务 id；同一幂等键重试不会重复创建任务。

常见问题

关于支持的模型、持久产物、回调，以及先试后接的快速解答。

HiAPI 支持哪些模型？

HiAPI 已支持精选的图像、视频与音频生成模型，包括 GPT Image 2.5 Flare 与 Sunburst。完整列表见模型页。

持久产物链接如何运作？

把 storage 设为 persistent，生成的输出会替你存好，并在任务结果中以持久链接返回。

可以用回调代替轮询吗？

可以。提供回调 URL，任务到达终态时 HiAPI 会主动通知你，省去轮询。

能先试模型再集成吗？

可以。在每个模型页用 Playground 试参数、看示例输出，写代码前先体验。
