Seedance 2.5 API 有何不同

字节跳动为更长、更可控的 AI 视频生产提供的强大能力

原生约 30 秒单次成片

Seedance 2.5 面向单次连续生成约 30 秒视频，减少拼接短片段带来的运动与主体一致性断层。

最多约 50 个多模态参考

可用图像、视频与音频组成的参考包引导 Seedance 2.5，锁定角色身份、产品细节、品牌风格与场景一致性。

文本、图像与参考工作流

Seedance 2.5 API 路径覆盖文生视频、图生视频与参考引导生成，适配广告、叙事镜头与产品故事。

首尾帧控制

通过起始与结束图像引导运动路径，让 Seedance 2.5 在两个关键帧之间形成更可控的镜头与主体运动。

原生音频与口型同步

作为音视频基础模型，Seedance 2.5 支持同步声音与对白驱动片段，减少完全拆分的音频生成环节。

区域级编辑

修改产品标签、背景或局部细节的同时，可尽量保留周围运动与光影。

3D 白模镜头预演

Seedance 2.5 强调 3D 白模预可视化，团队可在高质量渲染前规划机位与空间调度。

面向生产的连续性

更长原生成片与更密参考，有助于 Seedance 2.5 在多镜头广告、电商演示与短叙事中保持主体一致。

Seedance 2.5 API 常见问题

了解 Seedance 2.5 的能力、工作流与 API 使用方式

什么是 Seedance 2.5 API？

Seedance 2.5 API 指以编程方式访问字节跳动 Seedance 2.5 音视频模型，支持文本、图像与参考引导的 AI 视频生成。

Seedance 2.5 视频最长多久？

Seedance 2.5 支持原生单次约 30 秒成片，可减少许多短视频生产中对多段短片拼接的依赖。

Seedance 2.5 支持多少参考？

公开材料描述 Seedance 2.5 多模态参考容量最多约 50 个，涵盖图像、视频与音频。

Seedance 2.5 支持哪些工作流？

支持文生视频、带首尾帧控制的图生视频，以及用于产品一致性、品牌风格与多镜头叙事的参考引导生成。

Seedance 2.5 是否生成带音频的视频？

Seedance 2.5 作为音视频基础模型，支持同步声音与对白驱动片段。

Seedance 2.5 在 APIMart 如何工作？

与 APIMart 上其他视频模型类似，Seedance 2.5 使用异步任务流：提交生成请求、获得任务 ID，再轮询或通过 webhook 下载结果。
