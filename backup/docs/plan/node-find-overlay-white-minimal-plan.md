# NodeFind 浮层 —— 参照黑色版极简结构、保持白色主题

## 任务概述
当前 `NodeFindOverlay.vue` 工作区版本（356 行，白色主题，带大标题/关闭按钮/搜索图标/动画等装饰）与
历史"黑色版"（159 行，极简 command-palette 结构）布局差异大。用户要"效果参考黑色版"，但主题保持白。

## 黑色版结构特征（要参考的"效果"）
- 无标题、无图标、无按钮 —— 面板顶部就是一条通栏大输入框
- 输入框透明底、大内边距（16px 20px），placeholder 提示"搜索节点（名称/类型）..."
- 下方紧贴结果列表；行内左右布局：左标签、右一个圆角类型 pill
- 选中行 = 整行浅色高亮；无分割线、无动画（仅 backdrop blur + 阴影）
- 面板整体：顶部居中浮层、白 0.96 透明度、大圆角(16-18)、blur 背景、深阴影

## 保持的白色主题
白面板(实白/近白)、灰黑文字(#111827/#374151)、浅灰 placeholder(#9ca3af)、
浅色行高亮(白底上用 rgba 黑/浅色系强调)、类型 pill 保留但现在白色用浅灰蓝调。
外层遮罩用当前白主题的浅渐变（从黑版的黑色遮罩换成淡色）。

## 改动文件
- `packages/canvas-core/src/plugins/node-find/NodeFindOverlay.vue`（仅此一个）

## 具体改动方向（待用户确认范围）
在现白版基础上，向黑色版的极简结构收敛：
1. **砍掉顶部 header 区**（"查找/搜索节点"标题 + 右上 ✕ 按钮）——黑版没有
2. **去掉搜索条外围的灰底搜索框 + 放大镜图标**，回归"面板顶部直接一条通栏 input"
3. 列表项：去掉相邻项之间的分割线 + 入场交错动画，改用黑色版那样"整行浅色 hover/选中高亮"
4. 选中态：黑版是纯浅色整行高亮；白版当前是青色强调 —— 需确认要"青色强调"还是"浅灰高亮"
5. 保留：顶部居中浮层、深阴影、blur、输入自动聚焦、无匹配提示、过滤逻辑不动
