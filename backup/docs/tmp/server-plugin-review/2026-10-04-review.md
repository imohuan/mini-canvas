+### 补记：MCP 工具重名守卫（修复时发现）
+
+Standards 审查提过一句"`mcp/server.ts` 的强转遮住真问题——没有重名守卫"。落实现时确认并修了：
+插件注册的工具若与内置工具同名（如都叫 `canvas.get`），MCP SDK 会抛 `Tool X is already registered`，
+**让整条 `/mcp` 返 500**（服务器上所有 AI 工具一起失效）。
+
+修法：注册前查重，命中则**跳过并警告**（不用"插件优先覆盖"——内置工具是宿主承诺的能力，被悄悄顶掉更危险）。
+补了 E2E 测试打真实 `/mcp` 端点验证：插件工具能被 `tools/list` 列出；同名时跳过、内置那个仍在、不 500。
+
