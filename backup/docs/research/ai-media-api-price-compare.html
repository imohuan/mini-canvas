必须知道的坑（6 条）

1. 超时必须设 ≥600 秒。H3 平均生成耗时 264 秒，默认 30/60 秒超时会误杀本来会成功的请求。 这个坑很隐蔽——你会以为是接口挂了，其实是自己超时杀掉的。
2. 审核双向且静默。返回 HTTP 200 但响应体为空，或响应头带 X-Content-Filtered: true。 排查时加 X-Debug-Filter: true。对「996」「35岁」等数字组合和医疗/金融词异常敏感。
  • 3. 并发天花板：H3 免费 2 并行 / 充值 15 并行，图片 RPM 只有 10
  • 4. 参考视频秒数会加进计费：5 秒输出 + 3 秒参考视频 = 按 8 秒计费
  • 5. 图片 URL 24 小时过期，别直接存数据库，必须及时下载转存
  • 6. Token Plan 不 cover H3——见上方套餐页红框

踩坑清单（可直接执行）

  • 超时设置：MiniMax H3 平均 264 秒，超时必须设 ≥600 秒，否则误杀成功请求
  • 审核静默失败：H3 返回 HTTP 200 但响应体为空，加 X-Debug-Filter: true 排查
  • URL 有效期：MiniMax 图片 URL 24 小时过期，阿里百炼图片 URL 同样 24 小时——必须及时转存
  • 抽卡成本：视频生成按成功次数计费，一条成片平均要 3 次，预算要乘 3
  • 参考素材计入计费：H3 的参考视频秒数会加进输出计费；Seedance 的输入视频时长也计入 token
  • 升档会重新抽卡：gpt-image 升 quality 档会生成不同的图，「Low 定稿 + High 出图」走不通
  • 订阅包不 cover 视频：MiniMax Token Plan 明确不含 H3，要跑视频必须按量付费
  • 先小额试水：第三方中转先充 10 元，并先试探能否退款
