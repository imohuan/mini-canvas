# 节点组（把一整组节点收藏进资产库）

> 插件：分组 group + 资产库（成品应用） · [返回总览](/plugins/parsed/node-ui/)

**一句话**：右键一个分组 →「收藏到资产库」，它连同里面的节点、连线一起存成一个 `.plumegroup`；
之后从左侧资源库拖到画布，或右键空白处「资源库 ▸ 节点组」，就还原成**一整组**。

这和[节点包](/plugins/parsed/node-ui/node-package)是一对：节点包包**一个**可视化节点，
节点组包**一组**节点。

## 一、收藏：右键分组 →「收藏到资产库」

弹出的还是「上传资产」那个弹窗，和收藏图片 / 视频 / 可视化节点是同一个：

| 预填项 | 值 |
| --- | --- |
| 文件 | `分组 1.plumegroup` |
| 保存位置 | 根目录下的「节点组库」（没有就自动建） |
| 标签 | 「节点组」 |

左栏的类型筛选里也多一项「节点组」，筛出来只有这些包。

## 二、包里装了什么

只收**这一组的整棵子树**：

- 组节点本身；
- 它的全部后代节点（含嵌套组）；
- 两端都在组内的连线；
- 每个节点的 `data` 与尺寸。

组外的节点、跨出组的连线一律不进包 —— 否则拖回来是一堆悬空的线。

子节点的位置本来就存的是**相对组的局部坐标**，所以只记原值就行。

## 三、还原：拖进画布 / 右键「资源库 ▸ 节点组」

三条入口落到同一件事：

| 入口 | 落点 |
| --- | --- |
| 左侧资源库拖到画布 | 指针位置 |
| 资源库行菜单「添加到画布」 | 视口中心，并取景 |
| 右键空白 →「资源库 ▸ 节点组」 | 右键位置 |

还原时：

1. 整组**一次事务**写进画布，撤销一次就整组退掉；
2. 只挪根节点到落点，子节点保持相对偏移（整组不会散开）；
3. 根的名字跟着画布现状去重（拖两次不会出现两个「分组 1」）；
4. 组内的图片 / 视频按 `resourceId` 换一次本机地址，换不到就保留原字段；
5. 整组建完**选中**，一眼看到「进来了一整组」。

包里如果有当前**没装插件**的节点类型，会跳过那几个并提示，不会让整组都建不出来。

## 注意事项

1. **收藏的是数据，不是截图**：组里的节点拖回来仍是可编辑的真节点。
2. **分类是「节点组」，不是「节点」**：两者在左栏筛选、右键二级菜单里分开。
3. **右键菜单是现算的**：资产库变了就重建，删掉一个组，它的菜单项立刻消失。
4. **入口由外壳注册**：`apps/web` 在画布会话绑定时注册这几条命令，
   正式构建（插件从 cloud-server 装载）与 dev 走同一条路。
