# plugin-agent 目录说明

这个插件分成几层，每层只放一类东西。找代码时先看“这件事属于哪一层”，再看对应目录。

| 目录 | 放什么 | 不放什么 |
| --- | --- | --- |
| `plugin/` | 插件外壳：注册、命令 id、系统事件名、`useAgent()` 取服务的小钩子 | 界面、业务逻辑 |
| `ui/` | 所有界面：对话面板、消息流、输入区、设置页、渲染小部件 | 状态与请求 |
| `service/` | 前端服务：会话状态镜像、发送、队列、目标、设置类动作 | DOM、样式、Vue 组件 |
| `model/` | 纯计算与类型：转录模型、队列折行、分支导航、工具卡数据 | 发请求、读写文件 |
| `api/` | 与后台通信：`AgentApi`、通知、队列偏好 | 界面状态 |
| `server/` | 后台实现：会话文件、队列调度器、运行时、路由 | 浏览器侧代码 |

## ui/ 下面再分三类

| 目录 | 内容 |
| --- | --- |
| `ui/conversation/` | 对话面板本体：`AgentConversation`、消息列表、输入区、滚动容器，以及它们的 `useAgent*.ts` 控制器 |
| `ui/settings/` | 设置页：模型、技能、MCP、提示词、审批规则、模板、标题模型 |
| `ui/render/` | 只负责“把数据画出来”的小件：Markdown、工具卡正文 |
| `ui/shared/` | 界面共用的小工具：资源标签生成、按键口径、滚动吸附、选中文案 |
| `ui/toolbar/` | 节点顶栏的“引用到 Agent”按钮 |

## service/ 下面按业务域分

| 目录 | 内容 |
| --- | --- |
| `service/session/` | 打开/刷新会话、事件流、发送一轮、重试、压缩 |
| `service/queue/` | 排队、引导、编辑、暂停，以及目标（goal） |
| `service/settings/` | 模型、技能、MCP、提示词、审批规则 |
| `service/agentService.ts` | 组装入口：造状态，把各域方法拼成一个服务对象 |

## 改动时的约定

- 新增界面放 `ui/` 对应子目录，不要放回 `src/` 根目录。
- 新增纯计算放 `model/`，并补一个 `.test.ts`。
- 新增与后台的请求放 `api/` 或 `service/`，不要在组件里直接写 `fetch`。
- 后台逻辑一律放 `server/`，它不参与前端构建。
