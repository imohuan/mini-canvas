# 多选

> `@plume-canvas/plugin-multi-select` - v0.1.2

Shift+拖框选 / Ctrl+A 全选 / Escape 清除.

## 注册项

### 声明的依赖 (export const inject)

- `'doc', 'selection'`

### 注册的插槽 (slots.register)

- `overlay`

### 快捷键

- `mod+a`
- `Escape`

## 安装

```bash
npm i @plume-canvas/plugin-multi-select
```

本插件随 plume-canvas 主程序自动安装；也可通过插件管理页手动装卸。
