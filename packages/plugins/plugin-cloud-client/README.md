# 云端连接

> `@plume-canvas/plugin-cloud-client` - v0.1.3

连上 cloud-server 后台：画布存档 / 生成动作 / 生成历史 / 实时跟随（不装它则画布只有本地能力）.

## 注册项

### 提供的服务 (ctx.inject / provide)

- `cloud-client:history`
- `cloud-client`

### 声明的依赖 (export const inject)

## 安装

```bash
npm i @plume-canvas/plugin-cloud-client
```

本插件随 plume-canvas 主程序自动安装；也可通过插件管理页手动装卸。
