# 连接线路径实验室（参考 UI）

这个目录里的 `edge-routing-lab.html` 是默认主题连线的**可视参考页**：
把组件当前支持的线型、控制点和避障矩形画出来，方便对照源码调试。

## 怎么打开

直接双击 `edge-routing-lab.html`，不需要安装依赖，也不需要之后台服务。

## 页面上有什么

- 顶部切换算法：原版四种（贝塞尔 / 直线 / 直角 / 圆角折线），以及
  自适应贝塞尔（当前默认）和正交避障。
- 中间是极简画布：两个节点带矩形框和端口，可以直接拖动；端口方向可改成上下左右。
- 右侧实时显示控制点坐标、折点数量、路径长度，以及路径是否穿过节点。
- 「复现截图场景」还原短缝起手的布局；「障碍布局」在中间放一个节点，
  用来观察避障路径怎么绕。
- 可以叠加显示原版路径、控制点和避障边距，方便对比同一组端口坐标下的差异。
- 「避障边距」是黄色安全区（节点矩形向外扩的范围）；「连线留白」是连线在安全区外
  再多让开的距离，默认 6px。设为 0 时连线会贴着黄框走。

## 和源码的对应关系

页面里的路径逻辑按 `src/components/edge/edgeGeometry.ts` 的规则重写了一遍，
包括字符串格式与参数默认值（最小曲率 80、直角伸出 20、折线圆角 5、
避障边距 18、避障圆角 8）。产品里实际绘制由
`src/components/edge/CustomEdge.vue` 完成，两者要一起改：

- 先在这页确认形状和参数；
- 再改 `edgeGeometry.ts` 和 `CustomEdge.vue`；
- 跑 `pnpm -C packages/plugins/plugin-theme-canvas test` 与 `typecheck`；
- 最后在真实画布里用「设置 → 边 → 连线」实测。

## 原来的问题

两个端口水平只隔 14px 时，原版贝塞尔仍把控制点各向外推 80px：

- c1.x = 440
- c2.x = 294

两者交叉 146px，曲线先鼓出去再折回，看起来像蛇。
自适应贝塞尔改为控制点长度取实际缝宽的一半，从数学上不再交叉。

更完整的记录见 `docs/问题整理/19-连接线短缝蛇形与避障Demo.md`。
