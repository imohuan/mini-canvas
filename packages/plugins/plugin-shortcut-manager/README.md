# 快捷键

> `@plume-canvas/plugin-shortcut-manager` - v0.1.3

快捷键帮助面板与设置页的快捷键配置（Ctrl/Cmd+/ 开合）.

## 注册项

### 提供的服务 (ctx.inject / provide)

- `shortcut-manager`

### 声明的依赖 (export const inject)

- ``

### 注册的插槽 (slots.register)

- `overlay`
- `settings.nav`

### 快捷键

- `mod`

## 安装

```bash
npm i @plume-canvas/plugin-shortcut-manager
```

本插件随 plume-canvas 主程序自动安装；也可通过插件管理页手动装卸。
