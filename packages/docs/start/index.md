# 入门

这条路线带你从零走到能独立写插件。**按顺序读，不要跳** —— 每一步都为下一步铺路。

```
① 这个项目是什么          （2 分钟，建立直觉）
② 本地开发环境            （5 分钟，跑起来）
③ ★ 极简实战              （30 分钟，动手写出前后端各一个插件）
④ 核心概念                （20 分钟，懂为什么）
⑤ 深入各层 / 后台服务      （按需查，写到哪里读哪里）
```

| 步骤 | 页面 | 你会获得 |
| --- | --- | --- |
| ① | [这个项目是什么](/start/about) | 知道这是什么东西、长什么样子 |
| ② | [本地开发环境](/start/dev-setup) | 一个跑起来的画布 + 后台 |
| ③ | [★ 极简实战](/start/quickstart-fullstack) | **亲手写出前后端各一个插件，并连起来工作** |
| ④ | [三层是怎么分工的](/intro/three-layers) → [七个原语](/intro/plugin-system) → [注册场](/intro/registries) → [生命周期](/intro/lifecycle) | 看懂 ③ 里每行代码为什么那么写 |
| ⑤ | [内核](/kernel/) · [数据层](/canvas-data/) · [渲染层](/canvas-render/) · [主题](/theme/) · [后台服务](/cloud-server/) | 任何一层任何机制的细节 |

> ③ 是全站最重要的一篇。写的过程中遇到的每个 API 都有跳转链接，
> 直达 [API 分类](/api/) 对应页 —— 学新技术最有效的方式就是先跑通再理解。

## 读完入门之后

- 手头有具体任务 → [示例 · 我想做 X](/examples/recipe-map)（按目标查抄法）
- 想查某个 API → [API 分类](/api/)（按名字查签名）
- 想看这台画布装了什么 → [插件分类](/plugins/)（活快照是真数据）
