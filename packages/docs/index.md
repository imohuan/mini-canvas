## 这个站是干什么的

它是给你项目的**文档站**，也是一个**插件功能展示台**。写文档的人只写 MD，
插件功能列表和组件预览会自动生成、直接可用。

想马上动手，看 [指南](/guide/)；想看有哪些插件，看 [插件功能](/plugins/)；
想试组件，看 [组件预览](/preview/)。
