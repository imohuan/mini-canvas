# 节点包（导出 / 导入 / 版本化）

> 插件：可视化节点 node-ui · [返回总览](/plugins/parsed/node-ui/)

**一句话**：一个可视化节点（它的界面 + 它用到的脚本）可以打包成 `.mcnode` 存进资产库，
之后从左侧资源库拖到**任何画布**，节点连脚本一起就位。

## 一、导出 / 收藏

`canvas_ui_package` 把"节点 data + 它声明的脚本"打成一个 `.mcnode`（ZIP 结构），存进资产库。
存完能从左侧资源库拖到任何画布。

## 二、导入

拖进画布 = **自动落脚本 + 还原节点**（带 `uiHtml` / `uiScripts` 一起）。

## 三、冲突就整包升版本

逐个脚本比 `sha256`：

| 情况 | 怎么做 |
| --- | --- |
| 本机没有 | 直接写入 |
| 同名同内容 | 用本机那份（**幂等跳过**） |
| 同名不同内容 | **整包升 `_vN`** |

### 升版本四处一起改，一处不能漏

| 位置 | 改成 |
| --- | --- |
| ① 脚本文件 | `scale.mjs` → `scale_v2.mjs` |
| ② 依赖声明 | `{ scale: … }` → `{ scale_v2: … }` |
| ③ 界面引用 | `name: "scale"` → `name: "scale_v2"` |
| ④ 节点标题 | `视频可视化` → `视频可视化_v2` |

> **不搞"一半升一半"**：会出现 v2 界面调 v1 脚本，看着能跑、行为是混的。

## 四、拖进画布时的落点与取景（2026-10-14 定，别改回去）

拖**可视化节点包**到画布上时，行为必须与拖图片/视频**一致**：

- **落点 = 指针位置**（把指针屏幕坐标换算成 flow 坐标，再往左上回退半个身位）。
  等价于"节点看起来落在指针处"，与图片那条路**逐像素相同**。
  三层入口都要把落点传下去：`createAssetNode`（资产库拖 / 文件名拖）、
  `LeftDrawer.onCanvasDrop`（文件系统拖）、`importPackFile`（没有指针落点时用**视口中心**）。
- **只选中，不取景**：拖拽那条路走 `selectNewNode`（只把新节点设为选中），
  **不走** `focusNewNode`（那是"按 F 聚焦"，会缩放平移视口）。
  **但**：菜单"添加到画布"那条路（没有指针落点、节点可能落在视口外）**照旧**取景。
- **名字跟着画布现状去重**：从包里建出来的节点名如果与画布上已有的撞了，自动接号
  （「跑一下」→「跑一下 2」；「可视化 3」→「可视化 4」）。

## 注意事项

1. **脚本冲突绝不覆盖本机已有的**：宁可整包升版本，也不动本机那份 —— 否则别的画布会跟着坏。
2. **落点漏传的后果实测踩过两次**：节点落进级联默认位、以及误触发"取景"。
