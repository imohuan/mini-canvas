# 活快照：这台画布现在装了什么

这一页**不是一个普通文档页** —— 它在浏览器里直接调画布的自省 API，
把你**当前这台画布**的真实注册情况摊出来。

数据来源是 `ctx.surface()`（怎么做到的见 [自省](/core/self-inspect)）。

<SurfaceReport />

## 怎么读这张表

- **插件**：现在在跑的插件、它们的状态、哪个卡住了缺什么依赖。
- **谁放了什么**：按插件归拢 —— 谁往注册场放了多少条、用了哪些种类；
  以及谁提供了哪些服务。**这就是"某插件注册了什么"的答案。**
- **服务**：服务名 → 谁提供的 → 有哪些方法。
- **注册场**：每种场有哪些键、各几条。
- **命令 / 生成工具 / 事件**：另三条轴。

## 看不到数据？

两种情况：

1. **你在纯静态预览里打开这一页** —— 那里面没有画布应用，自然读不到。属正常。
2. **你本地开着画布应用，但仍读不到** —— 检查应用是否暴露了 `window.MiniCanvasUI`
   （成品应用默认会暴露）。

想在别的环境里用，也可以让后台把快照转成 JSON 下发，页面顶部那块
`数据源` 会显示当前用的是哪条路。
