# 活快照：这台画布现在装了什么

这一页**不是一个普通文档页** —— 它在浏览器里直接调画布的自省 API，
把你**当前这台画布**的真实注册情况摊出来。

数据来源是 `ctx.surface()`（怎么做到的见 [自省](/core/self-inspect)）。

<SurfaceReport />

## 怎么读这张表

- **插件**：现在在跑的插件、它们的状态、哪个卡住了缺什么依赖。
- **谁放了什么**：按插件归拢 —— 谁往注册场放了多少条、用了哪些种类；
  以及谁提供了哪些服务。**这就是"某插件注册了什么"的答案。**
- **服务**：服务名 → 谁提供的 → 有哪些方法。
- **注册场**：每种场有哪些键、各几条。
- **命令 / 生成工具 / 事件**：另三条轴。

## 数据从哪来（页面顶部「数据源」会写明）

按顺序试，第一个成功就用：

1. **传入的 `url`** —— 后台的快照接口，或自建 JSON。给后台用最省事。
2. **同页运行中的画布应用** —— 页面上就有 `window.MiniCanvasUI` 时，当场读实时数据。
3. **内置快照 `public/surface-snapshot.json`** —— 一份**真实采集**的快照，随仓库走。
   所以这一页**默认就有真数据可看**，不依赖你有没有开应用。

### 想更新内置快照

在跑着画布应用的页面里打开这一页，点右上角「**重新采集**」——
它会把当前运行中的画布采一份快照并下载成 `surface-snapshot.json`，
拿它覆盖 `packages/docs/public/surface-snapshot.json` 即更新。

### 为什么不能"直接读别的标签页"

浏览器不允许跨源（或跨标签页）读别的窗口的全局变量，实测会报
`Blocked a frame ... from accessing a cross-origin frame`。
所以"看实时"要么**同源注入**（后台把文档站和画布应用放同一个源下），
要么**由后台把快照转成 JSON 下发** —— 两条路都需要一点配合，这才有了内置快照这条兜底。

## 有一项现在读不到：插件"声明"了使用哪些服务

`ctx.surface()` 的 `services` 轴回答的是"**谁注入了**什么服务"（提供方），
但**没有**列出每个插件在模块里 `export const inject = [...]` 声明用了哪些服务（消费方）。

所以这一页现在的"谁提供了服务"是准的，"**谁使用了哪些服务**"还缺一环。
补法很轻：后台把每个插件的 `inject` 字段带上（插件清单里加一项），
页面再按它归拢即可 —— 不用改自省 API 本身。
