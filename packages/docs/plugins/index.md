# 插件总览

画布上的一切功能都是插件装上去的。这一页分三块：

- **核心插件**：菜单、右键、小地图、对齐……这些是画布自己带的"底子"。
- **自带的节点与工具插件**：文本 / 图片 / 视频 / AI 工具等，跟着应用一起启动。
- **可安装插件**：用户在「插件管理」里自己装卸的。

想看你**当前这台画布**上到底装了哪些、各自注册了什么 → [活快照](/plugins/live)。

## 核心插件

这几个是画布的"地基"，缺了画布就不成型。它们自带、不可装卸。

| 插件 | 干什么 | 详情 |
| --- | --- | --- |
| 默认主题 `theme-default` | 节点长什么样、连线长什么样、背景长什么样 | [看详解](/plugins/theme-default) |
| 渲染宿主 `canvas-render` | 把数据画到屏幕上，并且是插件系统的"装配入口" | [看详解](/plugins/canvas-render) |
| 底部状态栏 `bottom-bar` | 节点底部的状态栏，以及栏上的动作按钮 | 见下方功能表 |
| Agent `agent` | 画布内的 AI 对话助手 | 见下方功能表 |

### 字段说明

| 标记 | 意思 |
| --- | --- |
| 自带 | 跟着应用一起启动，用户卸不掉 |
| 可安装 | 用户可以在「插件管理」里自己装、自己卸 |
| 有后台 | 这个插件还有一半跑在后台 |
| 独立产物 | 有单独的产物文件，能经插件管理从清单加载 |
| 权限 | 后台插件声明的权限 |
