# 画面推演 - 5秒前

**LibTV 公开说明**：基于物理逻辑，反推 5 秒前的动作起因。

**什么时候用**：给成片补“前情”，或检查一个动作在物理上是否说得通。

## 可直接粘贴的模板

```text
Starting from the supplied image, reconstruct the same scene exactly 5.0 seconds earlier.
Output one cinematic still, not a comic grid.

PRESERVE FROM SOURCE IMAGE: exact character identity, face, hairstyle, body proportions,
wardrobe, props, setting, camera position, lens, framing, palette, and light direction.
Do not add a new main character, do not change the costume, do not move the location.

CAUSE RECONSTRUCTION — work backward from the visible end state:
1. What is visibly in motion or displaced? [hair, cloth, water, smoke, objects].
2. What force or action most likely caused it? [push, throw, fall, turn, impact].
3. Where was the body 5 seconds ago? [stance, hand position, gaze direction].
4. What was already true in the environment? [same furniture, same weather, same light].

Render the single most plausible earlier moment. Keep the same camera and exposure.
Do not add flashbacks borders, sepia, dream effects, text, or watermark. Photorealistic
cinematic still, aspect ratio same as source image.
```

## 填写要点

- 反推时最容易“换场景”；把固定家具、窗户、光源位置写进 `environment already true`。
- 如果原图有明显破损或水花，先列出它们，再问“什么动作会在 5 秒内造成这个结果”。
