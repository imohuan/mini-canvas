这套 DEMO 真正解决什么

  • 审核：两个选项 + 规则摘要，危险能力先说清。
  • 技能：有封面就大卡，没封面也好看；搜索、分类、详情。
  • MCP：服务列表 → 展开工具，引用整个服务或单个工具。
  • 模型：按模型名识别平台，显示官方图标，默认/视觉能力常显。

接入现有 Dropdown 时

DEMO 只画菜单内部。浮层定位、翻边、点击外部关闭仍交给现有 Dropdown；把 .menu-sheet 的内容放进它的 default 插槽即可。

图标来自开源项目 lobehub/lobe-icons（MIT），已内联，离线也能显示。普通工具图标统一用 24 格线性 SVG，与模型平台标志分开使用。

选择方案后，可继续把对应菜单接入 AgentConversation.vue。 演示数据均为示例。
