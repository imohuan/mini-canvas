定价常见问题

计费到底怎么运作？+−
EvoLink 是完全预付费、按量计费的。你充值积分余额（1 积分 ≈ $0.0147），每次 API 调用精确扣除该次调用的费用——视频/音频按秒、图像按张、大模型按 token。没有订阅、没有席位费、没有最低月消费。
积分会过期吗？+−
充值积分永不过期。活动赠送的积分可能带有效期，领取前会在计费控制台明确展示。
为什么你们的价格比官方 API 低？+−
我们以批量价格采购算力，并把大部分折扣让给你。每个 SKU 的供给通道——官方或 beta——直接标注在模型 ID 里，两条通道的价格并排公示。
视频生成怎么计费？+−
按生成视频的秒数计费，分辨率和模型档位有对应倍率。上方表格展示的是最低可用费率；每个模型页有完整的分辨率 × 时长矩阵。
支持哪些支付方式？+−
银行卡（Stripe，支持保存卡片与自动充值）、支付宝和微信支付、以及企业公对公打款。活动兑换码可在计费控制台使用。
可以开公司发票吗？+−
可以——发票在控制台自助开具。设置一次公司抬头后，任意充值都可以生成、下载或邮件发送带签章的发票。
有免费试用的方式吗？+−
创建账户和 API Key 不需要信用卡。每个模型页的在线试玩可以让你在充值前预览输出质量。
有批量或企业折扣吗？+−
有。如果团队月消费超过约 $5,000，把预计用量发给我们——承诺消费可获得批量价格、更高限流与专属支持通道。
生成失败会扣钱吗？+−
不会。无论是上游报错、超时还是容量不足，失败的请求不会进入你的账单，也无需任何申诉流程——失败就是不收费。
