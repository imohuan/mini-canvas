# 连接线路径 Demo：短缝蛇形与避障

## 现在有什么

- Demo 页面：`docs/tmp/edge-routing-lab.html`（单文件，无构建，直接打开）。
- 原版四种线型：贝塞尔 / 直线 / 直角 / 圆角折线，逻辑取自
  `packages/plugins/plugin-theme-canvas/src/components/edge/edgeGeometry.ts`。
- 新增两种路径：自适应贝塞尔、正交避障。
- 两个节点可拖拽，四个方向的端口可切换；右侧实时显示控制点、折点、路径长度和穿节点次数。
- 顶部「复现截图场景」还原短缝布局；「障碍布局」在中间放一个节点，用于比较三种模式。

## 蛇形的根因

原版贝塞尔：

```ts
const distX = Math.max(Math.abs(targetX - sourceX) * 0.5, app.minCurvature)
const c1x = sourceX + sourceSign * distX
const c2x = targetX + targetSign * distX
```

默认 `minCurvature = 80`。截图布局中源端口 x=360、目标端口 x=374，
水平缝只有 14px，控制点却各向外伸 80px：

- c1.x = 440
- c2.x = 294

两条控制臂越过彼此 146px，曲线先向右鼓、再折回，于是看起来像蛇。
这不是节点位置异常，而是固定最小曲率与短缝冲突。

另外，原版贝塞尔只判断 `Left` 端口，`Top` / `Bottom` 端口的控制点仍在水平方向，
上下端口也会出现先横拐再回来的形状。

## 新增算法 1：自适应贝塞尔

控制点沿端口法线伸出，长度按实际缝宽收缩：

- 相对端口：`k = min(轴向距离 / 2, 180)`，保证 c1 不越过 c2；
- 同向或垂直端口：`k = clamp(弦长 × 0.32, 22, 140)`；
- 上下端口使用端口法线，不再固定走 X 轴。

截图场景中 k = 7px，路径长度从原版 189px 降到 152px。

## 新增算法 2：正交避障

1. 每个节点矩形向外扩 `margin`（默认 18px）；
2. 取端点和所有外扩矩形边界坐标组成稀疏网格；
3. 在网格边上跑带转弯惩罚的 A*，边不得穿过外扩矩形；
4. 合并共线点，给拐角加圆角，再在端口方向补一小段出线。

这个模式适合「连接线不许穿过节点」的场景。截图场景会从上方绕过去；
中间放障碍节点时，路径从障碍上方绕行，实测穿节点 0 处。

避障路径仍然是从端口法线出线再绕行，圆弧段按二次贝塞尔近似，不是严格的恒定曲率圆弧。
如需接入产品，建议把 A* 的障碍矩形范围限制在当前视口附近，避免节点很多时网格过大。

## 怎么验证的

- 用仓库测试里的固定期望逐条比对原版输出：
  - `M 0 0 C 80 0, 20 0, 100 0`（bezier）
  - `M0 0L20 0L100 0L100 0L180 0L200 0`（step）
  - stepOffset=10 时为 `M0 0L10 0L100 0L100 0L190 0L200 0`
  - smoothstep 输出包含 `Q`
- 用 Chrome 实测四种原版模式、两种新模式、端口方向切换、节点拖拽、障碍布局；
  控制台无报错，路径 d 与右侧诊断同步更新。
- 页面提供 `window.__edgeLab`，可在控制台按坐标直接调用路径函数做对比。
