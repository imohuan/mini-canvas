现在的问题是：要授权的工具调用被折叠在工具组面板里，用户先得展开组、再展开那条命令才看得到“允许 / 拒绝”； 同时“运行 …？”这句标题把整条命令塞进去，和按钮抢宽度，命令被挤成一团。

现在

图标 + 标题 + 按钮同排，说明挤在窄列
>_
运行 ffmpeg -version 2>&1 | Select-Object -Firs t 2; Get-ChildItem...？

这条命令会在当前项目里执行。

问题
  • 命令被按钮挤到只剩半行，出现「Firs t 2」断词
  • 说明和标题抢同一条视觉基线

改成

标题一行，命令单独一块，说明一行，按钮自己一行
Agent 想执行一条命令
ffmpeg -version 2>&1 | Select-Object -First 2; Get-ChildItem .\assets\audio

这条命令会在当前项目里执行。只读取 ffmpeg 版本和音频目录，不会修改文件。

好处
  • 命令完整换行，不会断在单词中间
  • 说明单独一行，读起来像一句人话
  • 按钮有自己的位置，点错概率更低
