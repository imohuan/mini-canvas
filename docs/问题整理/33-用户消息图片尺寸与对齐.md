# 33 · 用户消息图片尺寸与对齐

- 状态：已完成
- 负责人：Codex
- 完成时间：2026-11-17

## 你的原话

> 这里你的 Agent 就是用户对话气泡，里面会上传图片。你这个图片 UI 存在问题：
> 首先，你的图片卡片有点小，可以再大一些。
> 然后，你的对齐方式应该是右侧对齐。

## 要解决的问题

1. 用户气泡里的图片卡片要明显大一些，能看清内容。
2. 图片要和用户气泡一样靠右对齐，而不是顶在左边。

## 范围与位置

- 页面：画布右侧 Agent 面板 → 用户消息（带图片）
- 参考代码：`packages/plugins/plugin-agent/src/ui/conversation/AgentMessageList.vue`（`.ac-user-images` 模板）、`packages/plugins/plugin-agent/src/ui/conversation/AgentMessageList.css`（本组件样式）、`packages/plugins/plugin-agent/src/ui/conversation/agent-composer/part1.css`（旧的错放样式）
- 相关资源：本问题没有图片（用户截图见对话记录）
- 关联问题：无

## 现在 vs 期望

| | 现在 | 期望 |
| --- | --- | --- |
| 图片尺寸 | 32px（只剩组件库按钮的 `icon-sm` 默认尺寸） | 200px 正方形，圆角 12px |
| 对齐 | 顶在整行最左 | 与用户气泡右缘对齐 |
| 圆角 | 6px（按钮自带 `rounded-md` 生效） | 12px |

## 问题原因

- 状态：已确认
- 复现步骤：在 Agent 输入区上传一张图片并发送，观察用户消息下方图片。
- 证据：`.ac-user-images` / `.ac-user-image` 的样式原先写在 `AgentComposer.vue` 的 `<style scoped>` 里；scoped 只作用于输入组件自身，消息流里的图片节点拿不到这些规则。实测修复前图片 32×32、圆角 6px、贴左；修复后 200×200、圆角 12px、右缘 1887px 与气泡一致。
- 根因：样式归属放错组件（scoped 不跨兄弟组件），并且单类名规则权重低于组件库按钮自带的 `rounded-md`。

## 修改方案

- 改哪里：把两组规则从 `agent-composer/part1.css` 移到 `AgentMessageList.css`；尺寸与对齐按用户要求调整；选择器加父级提高权重。
- 怎么改：容器 `justify-content: flex-end` + `align-self: flex-end`；图片 200×200、圆角 12px、`object-fit: cover`；悬停不画额外底色。
- 为什么这样改：样式跟着真正渲染它的组件走，scoped 才能生效；父级选择器压过按钮默认圆角与尺寸。
- 风险 / 影响面：只影响用户消息里的图片；输入区附件缩略图使用另一套类名，不受影响。
- 验证方式：新增源码契约测试 + Chrome 实测测量尺寸与右缘位置。

## 验收标准

- [x] 用户消息图片为 200×200（大于原来的 32px），圆角 12px
- [x] 图片容器靠右，图片右缘与用户气泡右缘对齐
- [x] 点击图片仍能打开大图预览
- [x] 输入区附件缩略图样式不变

## 不能动

- 不改图片上传与预览逻辑（`openPreview`）
- 不改输入区附件的类名与布局
- 不动消息流其它排版（气泡宽度、时间/复制/编辑操作条）

## 假设与待确认

- 假设：多图横排时从右往左排、超出宽度换行，仍保持右对齐。
- 待确认：无。
