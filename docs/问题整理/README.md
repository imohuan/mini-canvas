## 怎么用

1. 每个问题一个文件，文件名格式是 `编号-简短标题.md`。
2. 截图和参考图统一放在 `images/`，文件名也带编号。
3. 新问题照 `_模板.md` 的格式写。
4. 先看文件里的「待确认」。还有空白的地方，说明需要你补一句。
5. 确认方向后，再按「验收标准」改代码。
