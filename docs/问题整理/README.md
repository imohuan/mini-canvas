# 问题整理

这里把你提的每一个问题，整理成 AI 能直接照着做的小任务。

技能入口：`.codex/skills/issue-briefing/SKILL.md`

## 怎么用

1. 每个问题一个文件，文件名格式是 `编号-简短标题.md`。
2. 截图和参考图统一放在 `images/`，文件名也带编号。
3. 新问题照 `_模板.md` 的格式写。
4. 先看文件里的「待确认」。还有空白的地方，说明需要你补一句。
5. 确认方向后，再按「验收标准」改代码。

## 这批要解决什么

先把设置界面和底部工具栏里最影响使用的地方理清：配置分组、正文排版、菜单状态色、快捷键配置入口，以及底栏按钮的显示与开合。

## 建议顺序

1. **先定方向**：01 的吸附设置归属、图片/视频分档 UI 形态，以及 04 的快捷键面板放在哪套设置皮。
2. **先修低风险、可单独验收的 UI**：03 菜单 hover、02 设置正文居中与拖拽角。
3. **再改交互入口**：05 的缩放下拉与状态栏图标切换、04 的快捷键配置页。
4. **最后做结构较大的 01**：分组重排会影响多处字段位置，先确认信息架构再动。

05 里的四条互不依赖，可以拆开单独做；04 与 05 的底部快捷键按钮有关，但可以分开验收。
