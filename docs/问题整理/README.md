# 问题整理

这里把你提的每一个问题，整理成 AI 能直接照着做的小任务。

技能入口：`.codex/skills/issue-briefing/SKILL.md`

## 怎么用

1. 每个问题一个文件，文件名格式是 `编号-简短标题.md`。
2. 截图和参考图统一放在 `images/`，文件名也带编号。
3. 新问题照 `_模板.md` 的格式写。
4. 先看文件里的「待确认」。还有空白的地方，说明需要你补一句。
5. 确认方向后，再按「验收标准」和「执行指令」改代码。
6. 执行完成后，在当前文档头部改成「已完成」，勾选验收项，填写执行记录。

问题文档和图片都直接放在本目录，不再按日期或批次建子文件夹。新增和更新任务只写根目录的 `01`–`12`。

## 这批要解决什么

这批文档按最新 `task-v1` 结构整理，覆盖设置页、浮层组件、画布下拉、底栏、Agent 面板、快捷键配置，以及项目页插件面板与上下文分层。

最关键的公共改动是 11：把 DropdownMenu、Select、Popover、Tooltip、ContextMenu、Combobox 的箭头、间距和选中样式统一到「外观 → 浮层」配置中，避免继续在 60 多处调用点各写一套偏移。
