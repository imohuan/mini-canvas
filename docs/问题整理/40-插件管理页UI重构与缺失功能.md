## 你的原话

看图，你这边的 UI 还有其他地方存在一些问题：

1. 左侧侧边栏中的画布没有空状态的显示 UI。可以参考「资产」，它没有列表的时候会显示一个空状态。
2. 左侧侧边栏中明明有对应的资源和类型，但是左侧的图片没有正确显示，被显示成了图标。按理说应该显示图片的缩略图。
3. 当前插件好像不止 24 个，先帮我看一看，很多 NPM 库好像没有发布。后面的库如果没有发布就暂时不用发布，因为还有地方没有修改。

UI 部分主要存在一些问题：

1. 描述显示不合理：插件卡片的描述展示的是库的名称，不合理。
2. 按钮逻辑有问题：插件有「更新」「卸载」「发布」三个按钮，按理说应该只有「发布」和「卸载」的切换效果，只有检测到更新时才出现「更新」按钮。
3. 「发布」按钮位置错误：插件系统不应该有「发布」按钮，发布是交给代码层的，不是给 UI 的。
4. 缺少插件详情页：点击插件时应进入详情页介绍它是做什么的。每个插件都是 NPM 库，有 README 文件，可以直接显示 README。

插件描述：给 README 添加描述，或者直接在 package.json 里写介绍，package.json 里写描述更好。

详情页是 README 渲染，README 可以引入第三方图片等资源，相当于是一个 Markdown 渲染 UI。

搜索有两个输入框，不合理，请简化。
点击进入详情时是二级菜单面板，可以检查平台「进入」配置项如何进入二级菜单（参考图 4）。

## 问题原因

- 状态：已确认
- 证据：图 1/图 3 红框显示卡片三个按钮与包名描述；图 2 显示画布侧栏空白无空状态；图 4 是平台页二级面板参考。
 - 根因（分项）：「发布」按钮是此前为实现「UI 触发发布到 registry」加的演示入口（usePluginManagerPage.ts:230），定位错了——发布属于开发流程（代码层 CLI scripts/publish-all.cjs），不属于插件使用者 UI；卡片描述直接取了包名而不是 plume.description；详情页此前完全没有设计；两个搜索框分别是「当前卡片筛选」和「NPM 搜索」，功能重叠。

- 插件数量核对结果：仓库 `packages/plugins` 下 34 个目录；`builtin-manifest.json` 只登记 24 个自带插件；
  未发布的 10 个（demo-kit、auto-save、history、cursor-effect、hot-reload、align-guide、align-arrange、canvas-export、node-find、node-image-compare）
  按用户口径暂不发布，等用户改完再说。

 左栏缩略图回归排查（2026-11-21 用户澄清）：图片和视频都需要缩略图，之前一切正常，现在变成通用图标——这是回归不是缺失功能。渲染分支本身健全（CanvasTreePanel.vue:148 按 child.thumb 渲染 img），thumb 由 nodeThumbUrl（composables/canvasTree.ts:212）从节点 data.imageUrl/posterUrl 取。候选根因待排查：① npx 环境装的 UI 包构建版本与仓库不同步；② 图片 URL 是 /api/canvases/.../resources/ 相对路径，跨画布或鉴权时加载失败；③ 问题 36 的「资源只认本画布」改动影响。排查时先在 DevTools 看 img 的 src 与网络响应状态。

## 修改方案

 - 改哪里：① usePluginManagerPage.ts 删「发布」按钮与确认弹窗、publishPkg UI 逻辑（服务端 /api/publish 保留给 CLI）；卡片按钮改「卸载」常驻 + 有更新时追加「更新」；② 卡片描述改 plume.description，包名放 meta 行；③ 新增插件详情二级面板：点击卡片 → 「← 返回插件列表」→ 渲染 README（引入 marked + DOMPurify，仓库目前没有 markdown 库）；README 来源走 npm registry 的 readme 字段（未安装的插件也能看）；④ 搜索框合并为一个（列表页统一按名字/包名筛选）；⑤ 画布左栏空状态参考 AssetTreePanel 补齐；⑥ 左栏图片资源用缩略图替代通用图标；
- 为什么这样改：对齐用户对「插件系统面向使用者」的定位；发布是开发者工具链，已在 CLI 提供。
- 风险 / 影响面：plugin-manager 包改动较大；README 渲染需要新依赖（marked）与 XSS 过滤（DOMPurify）；服务端 catalog 若要带 README 需要读插件目录的 README.md 文件（已有 npmInstalled 目录结构可读）。
- 验证方式：Chrome 打开插件管理页逐项核对：按钮组合、描述文案、点卡片进详情、README 渲染（含图片）、返回按钮、单一搜索框；画布侧栏空状态与缩略图截图对比。
