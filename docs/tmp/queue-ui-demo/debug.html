主题

踩过的坑 · 规则清单（错 → 对）
  1. 队列与输入框零间隔：容器 margin:0，与输入框边框重叠 1px；宽 90% 居中。
  2. 只有外层圆角：容器 14px，内部行 border-radius:0；容器四边 1px 描边。
  3. 目标两阶段：未发送=输入框内侧顶部（只写「目标」二字）；已发送=聚合容器里的一行。两处都要有口径开关。
  4. 预算紧跟「目标」之后，无背景、无边框；行内 contenteditable 编辑，宽度自适应。
  5. 下划线用 text-decoration（非 border-bottom）——边框会把文字压偏。
  6. 口径只有两态：「已用预算」⇄「剩余预算」，都叫预算；开关在关闭按钮左侧、样式与它一致，点击换图标。
  7. token 单位换算：国际 k/M/B/T，中文 万/亿/万亿；不甩长数字串。
  8. 队列暂停键：骑在队列与输入框分界线上、水平居中，图标+文字+条数，文字带「队列」前缀。
  9. 引导是纯图标按钮（带文字会被挤成竖排折行）。
  10. 回到底部：放在消息区内部、底部居中。
  11. 同一行相邻文字：字号/行高/盒高/内边距必须一致（对齐的根因就是字号不同）。
  12. 极端防护：次要信息可压缩/隐藏，按钮永不被挤走；超长文本单行省略号；行高稳定。
  13. 暗色下的 hover：用叠加半透明，不要替换不透明底色（否则发白）；--ui-* 亮暗两套都要有值。
