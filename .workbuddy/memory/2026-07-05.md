### 修复：批量连线空白区域释放时无 context menu

**问题**：SelectionFrame 多选框 connect-handle → batch connect 拖到空白区域松开时，不弹出"创建节点"连接菜单。单节点连线无此问题。

**根因**：`useCanvasConnection.onBatchConnectEnd` 用直接 DOM mouseup 监听（不走 VueFlow `@connect-end` 事件），空白区域没有任何处理直接 return。ContextMenuPlugin 只监听 `eventBus` 的 `connectEnd` 事件，所以批量连线到空白时 ContextMenuPlugin 永远收不到事件。

**修复**（`useCanvasConnection.ts`，两处同步：主工作区 + `.worktrees/fix-canvas-core-stability`）：
- `onBatchConnectEnd` source/target 分支各加一步"空白区域"处理：
  ```js
  canvas.connectionState.hoverTarget = { type: 'pane' }
  canvas.connectionState.snapTarget = null
  eventBus?.emit('connectEnd', event)
  ```
- bodyNode/bodySource 命中后加 `return`，防止 fall-through 到空白区域
- `eventBus.emit('connectEnd')` 是同步的，在 `resetBatchConnectState()` 清空 `activeConnection` 之前执行，ContextMenuPlugin 能读到正确状态
